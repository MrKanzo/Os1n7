# Pocket Audit 2.8

Окремий експериментальний Android-проєкт у гілці `pocket-audit`. Основний Os1n7 не змінюється.

Завантажте сюди незмінений архів `Pocket_Audit_2.8_source.zip` (без ключів підпису). GitHub Actions автоматично збере його. У результатах запуску буде тестовий debug APK і непідписаний release APK.

Для встановлення поверх старої версії release APK потрібно підписати тим самим ключем Pocket Audit. Debug APK має інший ключ. Не видаляйте стару програму, якщо потрібно зберегти її дані.

Системний фаєрвол використовує локальний ADB, потребує явного спарювання через бездротове налагодження та перевірки сумісності з HyperOS. Не перевірено на реальному телефоні.
