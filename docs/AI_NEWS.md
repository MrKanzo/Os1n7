# Os1n7 — Новини ШІ (v0.8.6)

## Ідея
Новий компактний фільтр **«🤖 Новини ШІ»** у вже наявному `Cyber Intelligence`, поруч із «🛡 Кібер» і «▥ Дані». Доступ також із трьох швидких кнопок хмарної бібліотеки. На головному екрані нових великих карток немає.

## Звідки публікації
- [OpenAI News](https://openai.com/news/rss.xml)
- [Google DeepMind Blog](https://deepmind.google/blog/rss.xml)
- [Hugging Face Blog](https://huggingface.co/blog/feed.xml) — поряд із повідомленнями компанії можуть бути дописи спільноти.

Це публікації першоджерел, а не загальне сканування всього медіапростору. Новина потрапляє до стрічки лише з датою, назвою, HTTPS-посиланням на домен відповідного видавця. Ніяких автоматично вигаданих заголовків або AI-підсумків не створюємо. Одне й те саме посилання не дублюється.

## Оновлення
`scripts/sync_ai_news.py` збирає RSS/Atom через GitHub Actions приблизно кожні 6 годин разом із наявною кіберстрічкою. При падінні одного джерела зберігається остання перевірена копія саме цього джерела. Дата `updatedAt` змінюється лише коли змінюється зміст. Архів обмежений 40 статтями, по 15 на джерело перед об'єднанням.

`scripts/translate_ai_news.py` використовує вже наявний локальний **Argos Translate** (англійська → українська) у GitHub Actions. Оригінальний текст зберігається у `originalTitle`/`originalSummary`; URL, дата й авторське джерело не редагуються. Зміни зберігаються в `content/ai-news.json` і автоматично стають доступні в додатку без нового APK.

**Увага:** автоматичний український переклад неофіційний і може бути неточним. Для інших мов працює існуюча на пристрої локальна система перекладу Os1n7 (мовна модель спочатку завантажується через Wi-Fi).

## Android
- `CyberIntelActivity.kt`: третя вкладка, окремий кеш `os1n7_cyber_intel/ai_snapshot`, локальні фільтри «Усі», «OpenAI», «DeepMind», «Hugging Face», безпечне відкриття першоджерела.
- `ServerLibraryActivity.kt`: компактна кнопка «🤖 ШІ» поруч із кіберновинами й статистикою.
- Розділення кіберкешу та ШІ-кешу: несправність однієї стрічки не видаляє іншу.
- Обмеження розміру JSON — 512 КБ; HTTPS + суворий список дозволених видавців, перевірка схеми, дублікатів і формату дати.
- Немає додаткових дозволів, зовнішніх AI API або фонового завантаження без відкриття екрана. Автоматичне завантаження новин відбувається на сервері GitHub, не на телефоні.

## QA
- `tests/test_ai_news.py`: URL-валідація, дати, fallback на стару копію, збереження перекладу.
- Після оновлення APK: Хмарна бібліотека → ШІ; перевірити всі 3 фільтри; перехід на офіційні сайти; офлайн-копію; збереження попередньої кіберстатистики.
- Невдалий мережевий запит має показувати офлайн-копію, якщо вона існує.
- Наявність нових статей і їхня дата залежать від актуальності RSS-публікацій і успішності GitHub Actions. Порожня стрічка до першого успішного синхронізування — нормальна; не заповнювати її штучними прикладами.
