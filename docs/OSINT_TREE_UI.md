# OS1N7 — Живе дерево OSINT (v0.7.5)

Новий екран `OsintTreeActivity` відкривається з головного меню («Живе дерево OSINT»). На відміну від готового постера, дерево створено **нативними Android View + Canvas**, тому всі гілки є справжніми кнопками та читаються Accessibility.

## Схема екрана

- Коронна частина: заголовок **OSINT** та підпис.
- Вертикальний інтерактивний стовбур зі смарагдовою лінією та двосторонніми гілками.
- 13 напрямків: пошук інформації, люди та профілі, соціальні мережі, домени та мережі, кіберрозвідка, витоки даних, фото та відео, геопросторовий OSINT, компанії та організації, Dark Web OSINT, аналітика, безпека та право, навчання та звіти.
- Кожна гілка відкриває 4 дочірні теми з короткими описами. Від дочірніх екранів є реальні переходи до наявних OS1N7 Academy, Lab, Graph, ToolCatalog, CyberIntel, SecurityCenter, CyberLaw та іншого контенту.
- При поверненні з категорії кнопка повертає саме до дерева, а не на головну сторінку.

## Анімації

- Повторюване вручну зростання стовбура й гілок (приблизно 2,2 секунди) через кнопку «Показати анімацію ще раз».
- Послідовна плавна поява плиток без використання GIF або зображень у пам’яті.
- **Постійна анімація:** світлові точки рухаються вздовж стовбура й кожної гілки, центральний блок злегка пульсує, напис «ЖИВА МЕРЕЖА» мерехтить.
- На головному меню картки з'являються послідовно; спільні заголовки сторінок плавно проявляються з коротким зсувом.
- Поважає системний режим «Вимкнути анімації»: за вимкненого Android animator scale всі плитки відразу видимі, а дерево пояснює, чому рух заблоковано.
- Пульсація автоматично зупиняється, коли Activity переходить у фон.
- Згасання/зсув сторінки під час відкриття категорії (130–230 мс).
- Штатні XML-переходи між Activity та зворотне повернення (220–260 мс).
- Без спеціальних дозволів, фонового опитування або мережевих запитів.

## Перевірка на Android

- [ ] Увійти з головного меню, прокрутити всі 13 гілок.
- [ ] Натиснути гілки зліва й справа; обидві мають відкривати правильні теми.
- [ ] Відкрити «Кіберрозвідка» → «Каталог інструментів» / «Кіберновини»; повернутися до вибраної гілки.
- [ ] Відкрити «Безпека та право» → «Кіберправо України».
- [ ] Кнопка назад із підкатегорії веде до дерева; назад із дерева — на головний екран.
- [ ] Після відкриття дерева почекати 3 секунди: точки повинні постійно рухатися по вертикалі та бокових гілках.
- [ ] Натиснути «Показати анімацію ще раз»: дерево виростає протягом ~2,2 с, плитки проявляються послідовно.
- [ ] Повернутися з підсторінки: рух відновлюється; після згортання програми анімація не має навантажувати CPU у фоні.
- [ ] У системі Android з «Видалити анімації» очікувати повідомлення і статичну, але повністю клікабельну карту.
- [ ] Перевірити анімації на повільному пристрої, у режимі енергозбереження, з масштабом шрифтів 1.3–1.5×.
- [ ] На вузьких дисплеях переконатися, що текст гілки не обрізаний.
- [ ] Перевернути телефон під час відкритої гілки та перевірити відновлення вибору.
- [ ] Підтвердити збірку Android APK в GitHub Actions перед установленням.

Це навігаційна карта, а не автоматизований сканер; її відкриття не створює OSINT-запити до сторонніх серверів.
