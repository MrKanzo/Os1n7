# Політика приватності OS1N7

**Дата перегляду: 22 листопада 2026 року.** OS1N7 (`com.mrkanzo.os1n7`) — навчальний Android-додаток для OSINT та кібербезпеки. Розробник проєкту: [MrKanzo на GitHub](https://github.com/MrKanzo), репозиторій: [MrKanzo/Os1n7](https://github.com/MrKanzo/Os1n7).

## Що зберігається на телефоні

- **Локальний профіль:** нікнейм, вибраний значок, обрані уроки.
- **Навчання:** пройдені уроки, тести, лабораторні місії, позначені налаштування захисту.
- **OSINT Graph:** справи, назви вузлів, власні нотатки та зазначені джерела. Користувач сам вводить ці дані. **Не додавайте чужі персональні дані без правової підстави.**
- **Офлайн-вміст:** завантажені матеріали, кіберновини та публічні заголовки звернень GitHub Issues; мережеві налаштування хмарної бібліотеки.
- **Оновлення:** локальний час останньої перевірки версії.

Ці записи зберігаються у приватному сховищі Android (SharedPreferences). OS1N7 наразі не має власної серверної реєстрації користувачів або сервера, на який автоматично надсилаються локальні справи, нікнейми чи навчальний прогрес. Програма не містить рекламного SDK або власної системи аналітики поведінки в перевіреному вихідному коді.

## Інтернет і сторонні сервіси

- **GitHub:** програма завантажує відкриті навчальні матеріали, новини, статистику, список публічних звернень та перевіряє релізи APK. Під час таких HTTPS-запитів GitHub, як і будь-який вебсервер, отримує мережеві метадані підключення (зокрема IP-адресу). Дані вводжених локальних справ у ці запити не додаються.
- **Перевірка доменів:** за вашою дією OS1N7 виконує DNS-запит до введеного домену або HTTPS HEAD-запит до введеного сервера. Зовнішній DNS-сервіс або віддалений сервер може фіксувати мережевий запит. Використовуйте власні чи дозволені цілі.
- **Фото/EXIF:** вибране вами через системний файловий засіб Android зображення читається локально. OS1N7 не завантажує фотографію на свій або сторонній сервер.
- **Локальний Termux / власний сервер:** коли користувач сам вмикає цей режим, програма звертається до заданого ним HTTP(S) сервера; для HTTP призначено лише локальну мережу. Власник сервера відповідає за його захист.
- **Зовнішні посилання:** посилання на сайти навчальних джерел, закони, кіберновини та GitHub відкриваються у браузері й підпадають під правила приватності відповідних сайтів.
- **GitHub Issues (відгуки):** під час створення звернення застосунок готує заголовок, опис, категорію та номер версії і відкриває форму GitHub у браузері. **Звернення не надсилається автоматично** — користувач має увійти в GitHub та окремо підтвердити публікацію. Якщо публікація відбудеться, текст є **публічним** і ним керує GitHub. Не вводьте у зверненнях паролі, адреси, телефони, приватні документи, ключі чи іншу конфіденційну інформацію.

## Доступи Android

Заявлені у поточному AndroidManifest дозволи: `INTERNET` (мережеві запити) і `REQUEST_INSTALL_PACKAGES` (користувацьке встановлення завантаженого оновлення APK у версії, що поширюється через GitHub). Автоматичне приховане встановлення не використовується. Доступ до файлу фото надається через системне вікно вибору документа.

## Зберігання та видалення

Локальні дані зберігаються, доки ви не зміните чи не видалите відповідний запис або не очистите дані додатка. В OS1N7 OSINT Graph можна видаляти окремі справи. У налаштуваннях Android: **Програми → OSINT Бібліотека → Сховище → Очистити дані** можна видалити локальний профіль, прогрес, кеш і справи; відновити їх після цього може бути неможливо. Видалення даних телефона **не видаляє** звернень, які користувач сам опублікував на GitHub; ними можна керувати за правилами GitHub.

У поточному AndroidManifest резервне копіювання даних додатка вимкнено (`allowBackup=false`).

## Захист і питання

Не використовуйте OS1N7 для несанкціонованого доступу, поширення чужих персональних даних чи порушення умов використання сайтів. OS1N7 не є державною службою, не афілійований із CERT-UA, CISA, FBI, NCSC UK або платформою GitHub. Назви установ та посилання вживаються лише для ідентифікації першоджерел.

Питання щодо цієї політики можна адресувати через [репозиторій проєкту](https://github.com/MrKanzo/Os1n7/issues) **без розкриття приватних даних**. Для роботи з Google Play перед публікацією потрібно додати окремий приватний контакт для звернень щодо персональних даних, розмістити політику на публічній вебсторінці та заповнити Data safety відповідно до фактичної поведінки додатка.

Цей документ описує перевірену реалізацію станом на зазначену дату. У разі змін мережевих функцій, SDK або збирання даних політика потребує оновлення.
