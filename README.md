# OS1N7

**OS1N7** — навчальна Android-бібліотека OSINT українською мовою. Kotlin, Android 8+, локальні практичні вправи, безпечні симуляції, графи навчальних досліджень, каталог інструментів, офіційні кіберновини, статистика й довідник кіберправа України.

> **Призначено для навчання та авторизованих досліджень.** Додаток не надає дозволу на доступ до чужих систем чи збір/публікацію чужих приватних даних. Перевіряйте законні підстави, правила кожного сервісу та чинну редакцію законодавства.
